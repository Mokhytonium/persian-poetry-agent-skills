# Persian Poetry Agent Skills 

دو اسکیل مستقل و ماژولار برای شعر فارسی:
- `skills/persian-modern-poet/`: شعر نو، سپید، آزاد و نیمایی
- `skills/persian-classical-poet/`: غزل، مثنوی، رباعی، دوبیتی، قصیده و قطعه

هر اسکیل `SKILL.md` با YAML frontmatter، منابع تخصصی، مثال‌ها و eval دارد. پوشه‌ی اسکیل را جداگانه در محل skills ابزار خود قرار دهید؛ پوشه‌ی اصلی ZIP خودش یک skill نیست.

## اصول
1. حفظ ایده‌ها و تصاویر موفق متن اولیه، حتی اگر عبارت‌بندی تغییر کند.
2. جداسازی تولید، نقد ادبی و راستی‌آزمایی فنی.
3. عدم ادعای وزن و قافیه بدون بررسی واقعی.
4. آرایه‌ها در خدمت معنا، نه چک‌لیست تزئینی.
5. پرسش‌گری هوشمند؛ فقط اگر پاسخ مسیر اثر را تغییر دهد.
6. هر بیت/بند باید کارکرد تازه‌ای داشته باشد.
7. تشخیص ابهام سازنده از نحو نامفهوم.

## اعتبارسنجی ساختار
`python scripts/validate_package.py`
این اسکریپت ساختار، فرانت‌متر، لینک‌های محلی و evalها را بررسی می‌کند؛ کیفیت ادبی یا صحت عروض را اثبات نمی‌کند.
